1. Purpose of the App

GateReco is used to manage warehouse gate operations from entry recording through GRN processing and exception review.

3. Signing In and Session Basics

  1. Enter Username.
  2. Enter Password.
  3. Click Continue.

Most screens include a logout action in the top app bar.

Change Password is available only to Admin and Warehouse Manager-like users. The new password must be at least 6 characters and confirmation must match.

4. Main Navigation

The application navigation can include Dashboard, Gate Entry, Reconciliation, and Reports. Desktop users see a sidebar, while mobile users see a bottom navigation bar.

6. Gate Entry Module

Gate Security, Manager, WH Mgr, and Admin see the general gate entry management view. Warehouse Executive sees the pending GRN-focused warehouse view.

6.1 Gate Entry List

  • search by challan, LR, vendor, or vehicle
  • filters: All, Gate In, Gate Out, Today, Yesterday, This Week
  • summary cards for Gate In, Gate Out, Today, and Yesterday
  • Load More for paginated records

6.2 Creating a New Gate Entry

Only Gate Security users can create a gate entry.

  1. Open Gate Entry.
  2. Click Create Gate Entry.
  3. Select Gate Status: Gate In or Gate Out.
  4. Enter one or more invoice/challan rows.
  5. Complete vendor and transport details.
  6. Optionally attach a file.
  7. Click Confirm Gate Entry.

Each invoice row includes Invoice/Challan Number, Invoice Date, PO Number, Part Number, Quantity, and UOM.

Validation includes challan uniqueness, duplicate prevention inside the form, and required-field checks.

6.3 Editing and Detail View

Warehouse Manager, WH Mgr, and Admin can edit an existing gate entry from the detail screen.

The detail view can show challan, direction, status, timestamps, vendor, transporter, vehicle, driver, items, and attachments.

7. Warehouse Executive Flow

Verification

Before GRN creation, executives verify:

  • Vendor Name
  • Vehicle Number
  • PO Number
  • Remarks

GRN Creation

Each item row includes:

  • Material Name
  • Received Qty
  • Accepted Qty
  • Rejected Qty

Rule: Accepted + Rejected must equal Received.

9. GRN Import Card

Manager-like users have a dashboard import card supporting CSV and XLSX files.

Required columns shown in the UI are poNumber, materialCode, grnNumber, and postingDate.

  1. Choose the file.
  2. Optionally enable Auto-run Reconciliation.
  3. Click Upload.

10. Reports Module

All main roles can access Reports & Exports.

Available report types:

  • Gate Entry Register
  • GRN Reconciliation Report
  • Exception Report

The report toolbar supports search, date range selection, report type selection, and export to Excel or PDF.

Report Summary Examples

  • Gate Entry Register: Total Entries, Gate In, Gate Out, Total Qty
  • GRN Reconciliation Report: Total Records, Matched, Exceptions, Pending, Qty Diff Total
  • Exception Report: Total Exceptions, Open, Resolved

11. Troubleshooting

  • If Reconciliation is not visible, verify the user role.
  • If Change Password is not visible, confirm the role is Admin or Manager-like.
  • If challan is rejected as duplicate, open the existing entry and verify whether it is already recorded.
  • If GRN creation is unavailable, confirm the record has been verified and GRN is not already completed.
  • If exported files are not visible, check the Downloads folder.

12. Recommended Operating Sequence

  1. Gate Security creates the gate entry.
  2. Warehouse Executive opens the pending GRN record.
  3. Warehouse Executive verifies vendor, vehicle, PO, and remarks.
  4. Warehouse Executive creates the GRN.
  5. Manager/Admin reviews dashboards and reconciliation results.
  6. Reports are exported when needed for review or sharing.
